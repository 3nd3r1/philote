## Candidates

Proposed 2026-11-09. Nothing checked for availability yet (domains, GitHub, package registries); collisions below are from memory.

| Name | Angle | Notes |
| --- | --- | --- |
| **Onto** | The source is an ontology; one source maps *onto* many frameworks | Short, says both ideas. Files: `app.onto`. Common word fragment, may be hard to search. |
| **Canon** | The source is canon and code is derived from it; cache keys hash the canonical form | Strong meaning. Collides with the camera company in search. |
| **Kiln** | You shape the clay (source) by hand; firing (LLM + pin) makes it hard, and you never reshape fired pottery, you refire | Good metaphor for "generated code is never edited". Kiln is also an existing AI dataset tool. |
| **Seed** | Like a random seed: same seed, same output | Reproducibility is the point. Very generic, hard to search. |
| **Lexicon** | Every word has a checkable meaning (P-007) | Long; fits the language more than the tool. |
| **Ordo** | Latin for order; strict and checkable | Neutral, short, few collisions that I know of. |

### From the Ender's Game books

| Name | In the books | Fit |
| --- | --- | --- |
| **Philote** | The basic particles everything is made of; philotic twines connect all things, and the ansible works through them | The ontology: a graph of concepts and their connections. Unusual, so easy to search. |
| **Outside** | In *Xenocide*, anything a mind holds a clear enough pattern of becomes real when a ship goes Outside | The thesis: describe it precisely and it gets made. Too common a word to use alone. |
| **Aiúa** | In *Children of the Mind*, the core of a being that gives pattern and order to everything under it | The source as the pattern behind the code. Obscure, and the accent is awkward in a CLI (`aiua`). |
| **Hive Queen** | Holds the pattern; the workers carry it out | D-001 exactly: the compiler owns the interfaces, model workers fill in bodies. Long, but fine as an architecture name. |
| **Speaker** | The Speaker for the Dead tells the true story of a life, without flattery | A name for the explain command (I-004), not the project. |
| **Ansible** | Instant communication across any distance | Taken by Red Hat Ansible. Unusable. |

These are words from Orson Scott Card's books. Fine for a side project; check trademarks before using one for a product.
