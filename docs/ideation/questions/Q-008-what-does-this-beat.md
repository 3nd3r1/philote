## Candidates

- Retargeting to another framework without edits.
- Model upgrades as a deliberate, reviewable rebuild.
- Reviewing a 5-line source diff instead of 400 lines of code.
- New candidate (P-008): AI writes the source, people review it, and the compiler guarantees the code matches. A SPEC.md gives no such guarantee.

E-001 measures the first three; E-002 tests the last.
