## Decision

The project is called **philote**: the repo, the language and the command (`philote check`). The candidates are listed in Q-010.

## Why

In the Ender's Game books, philotes are the particles everything is made of, and philotic twines connect all things. That matches the source: an ontology of concepts and the connections between them. The word is unusual, so it's easy to search for, and it was free on GitHub.

## Consequences

- Philote is a term from Orson Scott Card's books. Fine for an open-source project; check trademarks before building a commercial product on the name.
- The Go prototype still calls its binary `specc`. It's throwaway, so it keeps that name.
